# XMind 用例自动化分层清单

来源：`tj_test/ui/test-cases.xmind`。这里的“API”指公开的 OpenAI 兼容 API；“混合”指用接口或 fixture 准备数据、浏览器验证页面；“暂缓”表示不适合首版，并非永远不测。

## 访问与鉴权

| XMind 用例 | 分层 | 决策 |
| --- | --- | --- |
| 本机默认无密码直接打开 WebUI | UI | 核心冒烟，浏览器直接访问工作台 |
| 配置浏览器密码后访问需先登录 | UI + 安全 | 二阶段；需要独立鉴权配置启动 Gateway |

## 对话与流式回复

| XMind 用例 | 分层 | 决策 |
| --- | --- | --- |
| 普通消息流式呈现并落定 | UI + API | 两层各保留一个核心场景 |
| Enter 发送与 Shift+Enter 换行 | UI | 浏览器键盘行为 |
| 发送过程中控件变化 | UI | 已覆盖发送按钮切换为停止按钮、输入框可用状态 |
| 空白内容不可发送 | UI | 前端交互边界 |
| 停止响应 | UI | 已编写慢速流终止及继续对话场景，待复验 |
| 多轮历史按顺序展示 | UI | 核心业务链路 |
| 超过 64KB 文本被拒 | API + UI | API 验证边界，UI 只验证提示 |
| 流式错误后可继续 | API + UI | 已覆盖；API 的异常完成标记问题以 BUG-004 跟踪 |
| 模型徽标或设置入口 | UI | 二阶段 |
| `/model` 切换预设 | UI | 已编写，断言当前会话模型徽标更新，待复验 |
| `@` 提及话题 | UI | 已编写持久会话造数与结构化提及断言，待复验 |

## XMind 之外必须补充的 API 用例

WebUI 用例不能覆盖公开 API 契约，因此额外建立以下黑盒集合：

- `/health` 无鉴权可访问。
- `/v1/models` 返回当前配置模型。
- 缺少或错误 API key 返回 401 和结构化错误。
- 普通聊天返回 OpenAI 兼容 JSON。
- SSE 分片 ID 一致、正文可拼接、以 `finish_reason=stop` 和 `[DONE]` 结束。
- 缺少消息、错误角色、多消息和错误模型返回 400。
- JSON Base64 图片和 multipart 文件成功上传并写入隔离媒体目录。
- multipart 单文件超过 10MiB 返回 413 且不落盘。
- 远程图片 URL 返回 400，服务端不会代替调用方下载外部图片。
- multipart 同时上传多个文件并逐一落盘。
- `session_id` 历史隔离，以及四个并发会话互不泄露上下文。
- 非法 JSON、带字符集参数的 JSON Content-Type 和不支持的 HTTP 方法。
- Base64 损坏与超过 10MiB 的边界行为。
- 请求超时、模型服务 5xx 和 SSE 中途异常。
